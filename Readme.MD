# 🛠️ S.P.A — Canivete Suiço

Uma **Single Page Application** com diversas ferramentas utilitárias no mesmo lugar, sem necessidade de instalação ou backend.

---

## ✨ Funcionalidades

| Ferramenta | Descrição |
|---|---|
| 💱 **Cotação de Moedas** | Converte valores entre USD e BRL |
| ⚖️ **Calculadora de IMC** | Calcula o Índice de Massa Corporal (masculino/feminino) |
| 🌡️ **Conversor de Temperatura** | Converte entre Celsius (°C) e Fahrenheit (°F) |
| 🚗 **Conversor de Velocidade** | Converte entre Km/h e Mph |
| 📦 **Conversor de Massa** | Converte entre Quilogramas (Kg) e Libras (Lb) |
| 🔢 **Regra de Três** | Calcula proporções simples (A:B = C:X) |

---

## 🚀 Como usar

Por ser uma SPA sem dependências externas, basta abrir o arquivo no navegador:

```bash
# Clone o repositório
git clone https://github.com/SamuelLacerdx/projeto-spa.git

# Acesse a pasta
cd projeto-spa

# Abra o arquivo principal no navegador
open index.html
```

---

## 🗂️ Estrutura do projeto

```
projeto-spa/
├── index.html   # Estrutura e conteúdo da página
├── style.css    # Estilos e tema dark mode
└── script.js   # Lógica das ferramentas e navegação SPA
```

---

## 🛠️ Tecnologias

- **HTML5** — estrutura semântica da aplicação
- **CSS3** — estilização, responsividade e suporte a dark mode
- **JavaScript (Vanilla)** — lógica de navegação SPA e cálculos

> Sem frameworks, sem dependências, sem build step. Puro HTML, CSS e JS.

---

## 🌙 Dark Mode

A aplicação conta com alternância de tema claro/escuro diretamente pela interface.
